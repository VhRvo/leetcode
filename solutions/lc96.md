# LeetCode 96. 不同的二叉搜索树

## 题意

给定一个整数 `n`，求以 `1, 2, ..., n` 为节点组成的**互不相同的二叉搜索树**有多少种。

## 思路：动作反推状态

### 第一步：枚举动作

面对 `n` 个节点 `1..n`，核心动作只有一个：

- **选择哪个节点作为根**

选定根 `k` 后，由 BST 性质：

- 比 `k` 小的 `k-1` 个节点构成左子树
- 比 `k` 大的 `n-k` 个节点构成右子树

左右子树各自又是一个规模更小的"同类子问题"，且互相独立。

### 第二步：反推状态

要计算这个动作的贡献，我们需要知道什么信息？

| 需要的信息 | 来源 |

|---|---|
| 可选节点有多少个 | 由节点总数 `total` 决定 |

因为 BST 的结构数量只取决于**节点个数**，与具体数值无关（`{1,2,3}` 和 `{4,5,6}` 的 BST 方案数相同）。

于是状态自然浮现：**dp[total]**

## 状态定义

```plain
dp[total] = total 个节点能组成的不同 BST 数量
```

## 转移方程

对于每个 `total`，枚举动作——选第 `root` 个节点作为根（`root = 1, 2, ..., total`）：

```plain
dp[total] = Σ dp[root - 1] * dp[total - root]    (root 从 1 到 total)
```

### 转移解读

- **动作**：选 `root` 作为根
- **左子树**：`root - 1` 个节点 → 方案数 `dp[root - 1]`
- **右子树**：`total - root` 个节点 → 方案数 `dp[total - root]`
- 左右独立 → **乘法**原理
- 不同的根产生不重叠的树 → **加法**汇总

## 边界与答案

- **边界**：`dp[0] = 1`（空树算一种，作为乘法的单位元）
- **答案**：`dp[n]`
- **填表顺序**：`total` 从小到大（1 到 n）

## 复杂度

- **时间**：$O(n^2)$
- **空间**：$O(n)$

## 代码

```rust
pub fn num_trees(n: i32) -> i32 {
    let n = n as usize;
    let mut dp = vec![0; n + 1];
    dp[0] = 1;
    for total in 1..=n {
        // 动作：选 root 作为根
        for root in 1..=total {
            // 左子树节点数
            let left = root - 1;
            // 右子树节点数
            let right = total - root;
            dp[total] += dp[left] * dp[right];
        }
    }
    dp[n]
}
```

## 具体推演（n = 3）

| root | 左子树 dp[root-1] | 右子树 dp[total-root] | 贡献 |
|------|--------------------|-----------------------|------|
| 1    | dp[0] = 1          | dp[2] = 2             | 2    |
| 2    | dp[1] = 1          | dp[1] = 1             | 1    |
| 3    | dp[2] = 2          | dp[0] = 1             | 2    |

$$G(3) = 2 + 1 + 2 = 5$$

## 小结

| 步骤 | 内容 |
|---|---|
| **枚举动作** | 选哪个节点当根 |
| **反推状态** | 需要知道节点总数 → 记 `total` |
| **定义 DP** | dp[total]：total 个节点的 BST 数量 |
| **转移** | 枚举根，左右子树方案数相乘再求和 |
| **边界** | dp[0] = 1（空树一种） |

核心就一句话：**先想"我能做什么"（选根），再想"做这件事需要什么信息"（节点个数）**。

## 备注

该递推式即**卡特兰数**：$C_n = \sum_{k=0}^{n-1} C_k \cdot C_{n-1-k}$，等价于 $C_n = \frac{1}{n+1}\binom{2n}{n}$。
