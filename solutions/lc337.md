# LeetCode 337. 打家劫舍 III

## 题意

给定一棵二叉树，每个节点有一个非负整数值。不能同时抢劫**直接相连的两个节点**（父子关系），求能抢劫的最大金额。

---

## 思路一：动作反推状态

### 第一步：枚举动作

站在某个节点上，我们面临唯一的决策：

- **抢**（rob）：获得当前节点的金额，但**子节点不能再抢**
- **不抢**（skip）：当前节点不得金额，但**子节点可以自由选择**抢或不抢

### 第二步：反推状态

要计算这两个动作各自的最优收益，需要从子树获得什么信息？

| 动作 | 需要子树提供的信息 |
|---|---|
| 抢当前节点 | 左、右子节点**不抢**时的最优值 |
| 不抢当前节点 | 左、右子节点**任意选择**时的最优值 |

两个动作分别依赖子树的不同状态——因此每棵子树需要**同时返回两个值**：

```plain
(best, skip)
```

| 返回值 | 含义 |
|---|---|
| `best` | 该子树根节点可抢可不抢，两者取最优 |
| `skip` | 该子树根节点**不抢**时的最优值 |

状态自然浮现：对每棵以 `node` 为根的子树，定义 **`dp(node) = (best, skip)`**。

---

## 思路二：树形 DP 如何消除重复计算

### 低效版的问题

`inefficient_rob(root, available)` 将"是否可以抢"作为**参数**传入：

```
inefficient_rob(root, true)   // 可以抢
    ├── inefficient_rob(left,  true)   // 不抢 root，左子可选
    │       ├── inefficient_rob(left.left,  true)
    │       └── ...
    └── inefficient_rob(left, false)  // 抢 root，左子不可抢
            ├── inefficient_rob(left.left,  true)
            └── ...
```

同一棵子树被从不同"状态参数"出发**重复递归**，时间复杂度退化为 $O(2^n)$。

### 根本原因

> 参数中携带了"状态"，导致同一个节点需要以不同参数被多次访问。

### 解决办法

> **把参数里的状态变量，改成返回值里的多个状态。**

让 `rob(node)` 直接返回 `(best, skip)` 两个值，一次后序遍历就能收集所有需要的信息，每个节点**只访问一次**，时间复杂度降为 $O(n)$。

---

## 状态定义

```plain
dp(node) = (best, skip)

best = 以 node 为根的子树，node 可抢可不抢时的最大收益
skip = 以 node 为根的子树，node 不抢时的最大收益
```

---

## 转移方程

设左子树返回 `(l_best, l_skip)`，右子树返回 `(r_best, r_skip)`：

$$
\text{rob\_root} = val + l\_skip + r\_skip
$$

$$
\text{skip\_root} = l\_best + r\_best
$$

$$
\text{best\_root} = \max(\text{rob\_root},\ \text{skip\_root})
$$

$$
dp(\text{node}) = (\text{best\_root},\ \text{skip\_root})
$$

边界条件：`dp(None) = (0, 0)`

---

## 代码

```rust
fn rob(root: Tree) -> (i32, i32) {
    match root {
        None => (0, 0),
        Some(root) => {
            let left  = root.borrow().left.clone();
            let right = root.borrow().right.clone();
            let (l_best, l_skip) = rob(left);
            let (r_best, r_skip) = rob(right);

            let skip_root = l_best + r_best;
            let rob_root  = root.borrow().val + l_skip + r_skip;

            (skip_root.max(rob_root), skip_root)
        }
    }
}
```

最终答案：`rob(root).0`（根节点可抢可不抢时的最大值）。

---

## 复杂度

| | 复杂度 |
|---|---|
| 时间 | $O(n)$，每个节点恰好访问一次 |
| 空间 | $O(h)$，递归栈深度等于树高 $h$，最坏 $O(n)$，平衡树 $O(\log n)$ |
